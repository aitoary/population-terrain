# 注目地点ガイド

対象は既存の `public/data/miyako-population.geojson` の全692メッシュ。新たな外部データは取得しない。UIの増減率は検証済み `PopulationDataset.byId` から読み、既存の計算・書式関数を共用する。以下は選定時の原精度の記録で、配信値の別管理には使わない。

操作パネルは「選択メッシュの詳細と人口推移 → この表示をコピー → 注目地点 → 表示設定」の順。注目地点は名前・2070年の2020年比・短い説明からなる3つの行で、初見向けの導入文を残す。2020年／2070年人口の大きな重複表示と地点別コピーは置かず、選択後に詳細内の共通コピーを使う。選択状態は既存のメッシュIDに追従し、任意の別メッシュを選ぶと3択の強調が外れる。

原本は `data/source-manifest.json` が固定する国土数値情報2024年版人口ZIP（SHA-256: `2ca30e11eaf5328098c93af59a11ec2f55e73a727c3359f297a4667c628c0d59`）。`npm run data:verify` は再取得・書換えをせず、公開GeoJSONの全7,612値をローカル原本の `PTN_YYYY` と照合する。

## 選定理由

| 名称・メッシュID | 原典ポリゴンの中心（経度, 緯度） | 選定理由 |
| --- | --- | --- |
| 中心部周辺 `594137744` | 141.934375, 39.647916667 | 全692件で2020年人口・2020→2070年の減少人数がともに最大。1,388.8053→414.4128人、974.3925人減、約70.2%減。人口集積の大きな柱の変化を入口にする。 |
| 市内北側 `594147883` | 141.978125, 39.739583333 | 中心部の候補から北へ約10km離れ、北緯39.71度より北の対象セルで2020年人口が最大。414.7807→116.7621人、298.0186人減、約71.8%減。中心部に近い減少率でも減少人数が違うことを比較できる。 |
| 内陸西部 `594132791` | 141.365625, 39.64375 | 中心部の候補から西へ約49km離れ、東経141.5度より西の対象セルで2020年人口が最大。39.3616→8.4915人、30.8701人減、約78.4%減。内陸の小規模なセルと人口集積のあるセルで、率と人数の違いを見る。 |

全域の人口規模・減少人数の上位と、北側／西側の候補を座標で比較した。減少率の上位3件ではなく、人口規模と地理的な広がりを重視した導入用の3例であり、市全体や地区全体の代表値ではない。

名称は既存の原典ポリゴンの座標に基づく大まかな位置表現。中心部周辺は既存の公式関連データで確認済みの宮古駅座標（`src/config/dataSources.ts`）から約1.4kmの位置。新たな町名・施設名や行政地区名を付けず、地区境界や特定施設の人口を意味しない。背景確認にも既存の地理院淡色地図を使用する。

人口は500mセル全体のPTN系列であり、PLATEAU建物の整備範囲や表示有無で選別しない。500mセル全体の人口である旨は選択メッシュ詳細に、建物なし・読込失敗が無人口を意味しない旨は「データについて・利用条件」にまとめる。

## 状態と操作

地点選択はAppの既存 `view` を `{ year: 2070, meshId }` に更新する。YearControlは既存の外部年変更・最終年の処理でタイマーを解除し、既存のURL effectが `history.replaceState` を行う。履歴・他クエリ・ハッシュの扱いを変えない。

カメラの要求回数だけを別に持ち、Cesiumの既存 `focusMesh` へ接続する。同じ地点を押し直しても再移動できる。Viewer・地形の読込中は要求を保持し、準備後に移動する。地形取得失敗時は原典ポリゴンの周囲を各方向0.02度広げて上空から移動し、山地に近づきすぎることを避ける。人口柱の基準高を0で代用しない。通常の年・ID変更でカメラを再移動しない。

共有は選択メッシュ詳細内の既存 `ShareLink` に集約する。コピー対象は常に現在のURLで、年またはメッシュ変更時にコピー状態をリセットする。Clipboard API失敗・非対応時は従来どおりアドレス欄からのコピーを案内する。地点選択後にさらに年やメッシュを変更しても、その現在表示を共有する。
